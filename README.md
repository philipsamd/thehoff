# AM&D Marketing App/Portal

Build a polished enterprise SaaS web application prototype called “AM&D Digital Command Center” for Philips Ambulatory Monitoring & Diagnostics. It is an internal DAM + campaign activation + workflow governance platform, similar to Brandfolder but tailored to healthcare marketing, regulated content, SEO, paid media, Seismic, OneSite/Contentful, Salesforce, Smartsheet, SEMrush, and analytics workflows.

Primary positioning: one governed place to find, approve, activate, and measure every digital marketing asset. The app should feel executive-ready, modern, Apple-like, and enterprise-grade with a Philips-inspired visual system: clean white and light gray UI, rounded cards, subtle shadows, refined typography, Philips blue accents, crisp iconography, and dashboard-style layouts.

Core app objective:
Move users from “Where is the latest file?” to “Here is the approved asset, linked to the campaign, tagged by product/persona/channel, ready for activation.”

Primary users:
- Digital Strategy Manager
- Campaign Manager
- SEO Lead
- Paid Media Manager
- Sales Enablement
- Agencies
- Brand
- Legal / Regulatory
- Sales users searching for approved assets

1. Home Dashboard
